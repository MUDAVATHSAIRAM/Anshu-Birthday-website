# Add Anshu's photos and videos

Put 15 JPG photos in `public/memories/`, named `photo-01.jpg` through `photo-15.jpg`.

Put 2 MP4 videos in `public/videos/`, named `video-01.mp4` and `video-02.mp4`.

## Email responses

The form sends answers to `mudavath.sairam.apd22@itbhu.ac.in` through FormSubmit. The first submission triggers an activation email. Confirm it once; later responses arrive directly.

## Run locally

1. Open the project in VS Code.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the localhost address shown.

## Deploy to Vercel

Upload the folder to GitHub, import it into Vercel, and keep the detected default settings.
